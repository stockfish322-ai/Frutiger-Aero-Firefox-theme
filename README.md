# 🌐 AeroPortal — Your Glossy Gateway to the Web

Bring back the glossy, colorful internet aesthetic of the late 2000s!

AeroPortal is a custom Firefox experience inspired by **Windows Aero, Frutiger Aero, and the sunny computer interfaces of the 2000s**.

Featuring bright green glass, glossy buttons, colorful gradients, soft shadows, and a nostalgic web portal layout.

## ✨ Features

- **Glossy Aero Design:** Transparent glass panels, reflections, gradients, and soft shadows.
- **Web Search:** A central search bar for searching the web.
- **Multiple Search Categories:** Web, Images, Videos, Maps, News, and Mail.
- **Quick Launch:** Shortcuts to Wikipedia, Google Mail, Reddit, and YouTube.
- **Advanced Search:** Additional search options.
- **Preferences:** Customization options for the experience.
- **Settings:** Access to portal settings.
- **Nostalgic Appearance:** Inspired by the late 2000s and early 2010s internet aesthetic.

## 📥 Installation Guide

Follow these steps to install AeroPortal in Firefox.

### Step 1 — Open Your Firefox Profile

1. Open Firefox.
2. Type `about:profiles` into the address bar.
3. Find the profile marked **This is the profile in use**.
4. Under that profile, click **Open Folder** beside Root Directory.

**Important:** Make sure you use the profile you actually use for browsing. Otherwise, the customization may not appear in your Firefox.

### Step 2 — Create the Chrome Folder

1. Inside your profile folder, look for a folder named `chrome`.
2. If it doesn't exist, create a new folder.
3. Name the folder exactly:

`chrome`

### Step 3 — Add the Files

1. Download the AeroPortal files from this repository.
2. Extract the downloaded files if they come in a ZIP archive.
3. Copy the provided files into the `chrome` folder you created.

Make sure the files are placed directly inside the `chrome` folder, not inside another nested folder.

### Step 4 — Enable CSS Customization

1. Open a new Firefox tab.
2. Enter `about:config`.
3. Search for:

`toolkit.legacyUserProfileCustomizations.stylesheets`

4. Set its value to **true**.

### Step 5 — Restart Firefox

Close Firefox completely and open it again to apply the customization.
